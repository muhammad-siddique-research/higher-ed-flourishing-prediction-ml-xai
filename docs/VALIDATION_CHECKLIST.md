# Publication-grade research validation checklist

These items are **not completed merely because they are listed**.

- [ ] Verify research authorization, source provenance and instrument license.
- [ ] Document scale coding, 24-item TQ scoring and construct validity.
- [ ] Report participants, cohorts, campuses, missing data and exclusions.
- [ ] Screen target leakage, repeated participants and survey item overlap.
- [x] Compare baseline, ElasticNet, Random Forest, XGBoost and LightGBM using original private data; publicly report aggregate internal CV metrics.
- [x] Publish privacy-conscious **model-level aggregate** held-out errors and held-out SHAP importance; per-fold respondent-level outputs remain restricted.
- [ ] Formally assess paired performance uncertainty and model-selection stability across resamples.
- [ ] Evaluate new-campus and new-cohort generalization where feasible.
- [ ] Audit measurement invariance and relevant group error uncertainty.
- [ ] Review SHAP stability and predictive versus causal interpretations.
- [ ] Establish student privacy safeguards, access controls and appeal routes.
- [ ] Independently evaluate any educational intervention before scale-up.
- [ ] Verify authorship, funding, ethical review and publication permissions.
